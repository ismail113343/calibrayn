# Calibrayn

A study companion that works on a student's own notes. It plans revision, adjusts how hard the
questions are, and checks whether the student's confidence matches their results.

This Space runs the demo. Use the sample notes on the Upload page. Do not upload private notes
here: the Space sends text to a hosted model.
